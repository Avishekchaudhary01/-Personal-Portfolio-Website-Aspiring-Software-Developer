# Personal Portfolio Website – Aspiring Software Developer

A responsive personal portfolio website created as a frontend development assignment.

## About the Project

This portfolio presents my profile, skills, projects, education, and contact information in a clean and responsive interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Git & GitHub

## Features

- Responsive layout for desktop, tablet, and mobile
- Sticky navigation bar
- Mobile navigation menu
- Smooth scrolling
- Animated section reveals
- Skills section with progress indicators
- Project showcase with GitHub links
- Education timeline
- Contact section
